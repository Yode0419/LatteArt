# LatteArt

替自己沖一杯、拉個花：在瀏覽器裡的 3D 咖啡杯上自由注奶、穿心收尾，上滑出杯後得到一張金框杯卡。杯子會跟著滑鼠或手機陀螺儀輕輕晃動。

https://yode0419.github.io/LatteArt/

- 純前端：ES modules + WebGL（自製光線追蹤 shader），不需建置
- 開發：在專案根目錄執行 `python3 -m http.server`，打開 `index.html`
- Design System：`design-system.html`
- 架構說明：[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
